# Shared circuits

Every `name.txt` in this folder is available at `https://circuits.kjeraglabs.no/name`.

1. Build the circuit in the simulator.
2. File > Save As (or File > Export As Text and paste into a file).
3. Save it here as `name.txt`. Use letters, digits, `-` and `_` only.
4. Commit and push. The link works about two minutes later.
